# Security Policy

## Reporting a vulnerability

Please report security issues in this action privately through [GitHub private vulnerability reporting](https://github.com/grolston/setup-aws-emulator/security/advisories/new). Don't open a public issue.

Include the action version, the workflow configuration, and the steps to reproduce. You can expect an initial response within a few business days.

## Scope

This repository covers the action itself: how it downloads, verifies, installs, and starts AWS Emulator, and how it exposes credentials and environment variables to the workflow.

Vulnerabilities in AWS Emulator itself should be reported to AWS. See [aws/aws-emulator](https://github.com/aws/aws-emulator) and the [AWS vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/).

## Supported versions

Only the latest release of the current major version receives security fixes.
